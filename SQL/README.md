# SQL Analysis

SQL was used to analyze the Uber ride dataset and generate business insights.

## Analysis Performed

- Total number of rides
- Total revenue
- Average fare
- Revenue by payment method
- Rides by city
- Ride status analysis
- Customer analysis
- Driver analysis
- Distance analysis
- Top-performing cities

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- AVG
- JOIN
- CASE
- Aggregate functions
