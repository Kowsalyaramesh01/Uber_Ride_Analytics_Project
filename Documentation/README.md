# Project Documentation

## Project Title

Uber Ride Analytics

## Objective

The objective of this project is to analyze Uber ride data and
identify useful business insights related to rides, revenue,
customers, drivers, payment methods, ride status, and cities.

## Tools Used

- Excel
- SQL / MySQL
- Python
- Power BI

## Analysis Performed

### Excel
- Data cleaning
- Basic analysis
- Data organization

### SQL
- Total rides
- Total revenue
- Average fare
- City-wise analysis
- Payment method analysis
- Ride status analysis

### Python
- Data cleaning
- Exploratory data analysis
- Data visualization

### Power BI
- KPI dashboard
- Rides by city
- Revenue by payment method
- Ride status
- Rides by gender
- Average distance by city
- Interactive filters

## Key KPIs

- Total Rides
- Total Revenue
- Average Fare

## Conclusion

The project provides an interactive view of Uber ride performance
and helps understand important business trends using data analysis
and visualization.
