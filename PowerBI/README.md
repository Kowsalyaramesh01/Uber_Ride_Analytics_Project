# Power BI Dashboard

Interactive Uber Ride Analytics dashboard created using Microsoft Power BI.

## Dashboard KPIs

- Total Rides
- Total Revenue
- Average Fare

## Analysis

- Rides by City
- Revenue by Payment Method
- Ride Status Analysis
- Rides by Gender
- Average Distance by City
- Rides by Payment Method

## Dashboard Features

- Interactive City filter
- Payment Method filter
- KPI cards
- Charts and visualizations
- Business insights
